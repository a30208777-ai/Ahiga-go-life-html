🪟 Instalação no Windows

Baixe o pacote oficial do repositório, descompacte e configure o ambiente automaticamente.

Baixar IA (.zip)

No terminal (CMD), execute:

pip install flask
python IA-ahigagolife.py

🍏 Instalação no macOS

Baixe o pacote ou clone via terminal para iniciar a IA:

Baixar Repositório (.zip) 
brew install python3 git
pip3 install flask
python3 IA-ahigagolife.py
← Voltar ao menu

🐧 Instalação no Linux

Ambiente compatível com gerenciadores de pacotes padrão:

Baixar Pacote (.zip) 
sudo apt update && sudo apt install python3 python3-pip -y
pip3 install flask --break-system-packages
python3 IA-ahigagolife.py
← Voltar ao menu
