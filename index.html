Ahiga Go Life

Selecione o seu sistema operacional para baixar e configurar a IA com atualização automática.

Instalação no Windows

Baixe o pacote oficial do projeto, descompacte-o e execute os comandos automáticos.

Baixar IA (.zip)

1. Descompacte o arquivo baixado.
2. Abra a pasta e execute o script de instalação ou abra o cmd na pasta e digite: pip install flask e depois python IA-ahigagolife.py


← Voltar

Instalação no macOS

Baixe o repositório ou use o terminal para clonar e rodar o sistema:

Baixar Repositório (.zip) 
brew install python3 git
pip3 install flask
python3 IA-ahigagolife.py
← Voltar

Instalação no Linux

Escolha o seu ambiente Linux ou use o pacote geral:

Baixar Código (.zip) 
sudo apt update && sudo apt install python3 python3-pip -y
pip3 install flask --break-system-packages
python3 IA-ahigagolife.py
← Voltar

Instalação no iOS (iPhone / iPad)

O iOS restringe execuções locais de terminal. Utilize via PWA:

1. Abra o link da IA no Safari.
2. Toque em Compartilhar.
3. Selecione "Adicionar à Tela de Início".

← Voltar

Outros Sistemas

Certifique-se de ter o Python 3 e o Flask instalados e execute o pacote:

Baixar Pacote (.zip)
